# Simplified Blackjack

A simple console-based Blackjack game written in C.

## About the Project
This game allows the player to draw random cards and choose between Hit and Stand. The goal is to get as close to 21 as possible without exceeding it. The dealer draws cards until reaching a total of at least 17.

## Features
- Random card generation
- Hit and Stand options
- Automatic score calculation
- Dealer turn simulation
- Win, Lose, and Draw results
- Bust detection

## Technologies Used
- C
- Standard C Libraries (`stdio.h`, `stdlib.h`, `time.h`)

## How to Run

Compile:
```bash
gcc blackjack.c -o blackjack
```

Run:
```bash
./blackjack
```
